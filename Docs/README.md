# AI Spend Audit

AI Spend Audit is a web application that helps startups analyze AI tooling expenses and identify potential cost-saving opportunities across products like ChatGPT, Claude, Cursor, GitHub Copilot, and API-based AI services.

The project generates rule-based audit recommendations, estimated monthly and annual savings, and shareable public audit reports.

## Tech Stack

### Backend
